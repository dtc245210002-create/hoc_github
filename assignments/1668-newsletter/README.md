# Phối màu newsletter — hoạt động 1668

Hai bản có cùng cấu trúc Bootstrap 5.3.3; màu được tách riêng bằng CSS variables.
Khung newsletter được xây dựng theo ví dụ trong đề vì trang bài tập không cung
cấp liên kết tải phiên bản Trello offline.

1. `index.html`: bảng tương đồng, tạo bằng quy tắc Analogous tại Adobe Color:
   #D73220, #D6204F, #D65220, #D620BC, #D67220.
2. `version-2.html`: bảng bổ túc, tạo bằng quy tắc Complementary:
   #D73220, #20D677, #96453C, #3E815E, #573B38.

Nguồn palette: https://color.adobe.com/create/color-wheel, ngày 06/10/2026.
Màu trung tính bổ sung giúp phân biệt nền trang, vùng văn bản và thẻ Kanban.

Bản 1 tạo cảm giác sôi nổi, sáng tạo; bản 2 cân bằng xanh lá và màu đất để
tạo cảm giác bình tĩnh. Màu đen/trắng được chọn theo độ tương phản của nền.

Mở trực tiếp hai tệp HTML để so sánh. Cần Internet để tải Bootstrap từ CDN.
Không cần JavaScript cho các thành phần tĩnh trong bản tin này.
